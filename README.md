# lpl‑nav
纯前端 LPL 观赛导航页，粉丝自制，**无后端、不收集任何用户数据**。

> 项目仅做跳转指路，不存放、不转载任何赛事视频内容，所有版权归对应平台与 Riot Games / 腾讯所有。

## ✨ 功能特点
- 聚合官方直播间、二路解说、俱乐部主页、赛程数据、社区、历年S赛回放、主题曲MV、选手信息
- 平台筛选：官网 / B站 / 虎牙 / 抖音 / 快手 / 小红书 / 微博 / 游戏分类
- 实时搜索，支持搜主播、房间号、分组标题
- 分组折叠/全部折叠，页面主题切换（浅色 / 深色）
- 一键**导出本地HTML备份**（救命稻草！网页挂掉、清缓存直接打开本地文件就能用）
- 复制直播间链接、复制房间号；键盘快捷键支持；回到顶部
- 适配电脑 + 手机移动端

> ⚠️ 本项目**没有导入**：只能自己导出存备份，不支持读取别人的配置文件。

## 🚀 直接使用
1. GitHub Pages 打开线上页面即可直接用
2. 重要：右上角设置 → **把整页存成本地文件**，下载一份 HTML 到自己电脑，作为离线备份。
- 线上访问异常的时候，双击本地备份HTML文件就能继续观赛。

## 📁 本地运行方式
把仓库下载到本地，直接双击打开 `index.html` 即可，**不需要服务器**，纯静态页面。

## ⌨️ 键盘快捷键
- `/`：跳到搜索框
- `Esc`：清空搜索，恢复全部卡片
- `Alt + R`：重置搜索（刷新）
- `Alt + S`：全部折叠 / 全部展开分组

> 手机不用快捷键，直接点界面按钮操作。
