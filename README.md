# lpl-nav
玩家自制纯净无广告 LPL 一站式导航，仅做链接聚合，不生产内容。
主打观赛工具，附带轻量化选手速查页面。纯静态 HTML，无需后端、数据库，部署简单。

## ✨ 功能介绍
### 主页面（核心）
- 直播平台入口、官方直播间聚合
- 二路OB / 解说主播分组导航
- 赛事数据、社区、讨论区快捷跳转
- 深色 / 浅色主题一键切换，主题配置本地保存

### 选手速查页
> 已做减法，降低维护压力，不堆大量需要持续更新的资料
- 选手搜索：支持ID、战队、位置检索
- 筛选：现役选手 / 退役名宿、上单/打野/中单/ADC/辅助
- 两种浏览模式：按身份分组｜按战队分组
- 选手侧边抽屉：ID、本名、战队、位置、选手梗、快捷链接
- 快捷链接规则：有超话才展示微博超话入口，不存在则不硬生成
- 配套功能：随机选手梗彩蛋、一键复制选手ID、导出选手名单txt
- 无榜单、无引战热门排行、无商城、无付费内容

## 📌 项目特点
- 纯静态页面，无API依赖，离线基础功能可用
- 零广告、无弹窗、没有追踪统计脚本
- 克制设计，不做复杂自动数据抓取，避免接口失效烂尾
- 结构通用，很容易二次修改为 LCK / LEC / LCS 其他赛区版本

## 📂 部署方式
1. 下载全部源码文件，保持目录结构：
   ├── index.html          # 主导航页
├── fan-index.html           # 选手速查页
└── LICENSE             # 开源协议
2. 直接本地双击打开即可预览；
3. 线上部署：Gitee Pages / Vercel / Netlify / 静态服务器都支持，上传文件即可。
