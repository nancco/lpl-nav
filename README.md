# LPL-Nav
> 🎮 干净简洁的 LPL 赛事直播聚合导航页

在线预览：https://nancco.github.io/lpl-nav/

## ✨ 功能特点
- 📺 聚合官方主舞台、备用流、二路OB主播、俱乐部官方账号，一键跳转直播间
- 📋 房间号一键复制，快速记录
- 💾 内置导出备份功能，修改页面内容前一键存档，防止改错崩溃
- 🖥️ 桌面端专属：右上角可折叠动画视频面板，可全屏播放；手机端自动隐藏，互不干扰
- 🌓 深色主题，适配观看比赛氛围，支持明暗主题切换
- 📱 移动端友好布局，手机打开也能正常浏览跳转

## 📌 说明
本项目为**个人粉丝自制静态页面**，仅做链接聚合导航，
与腾讯、Riot Games、B站、虎牙、斗鱼等平台无任何隶属关系，不承载、不转播赛事流。

直播间链接会随主播房间变更、账号迁移而失效，发现失效链接欢迎反馈。

## 🛠️ 使用方式
两种打开方式任选：
1. 在线访问：https://nancco.github.io/lpl-nav/
2. 本地使用：下载仓库内 `index.html`，双击直接在浏览器打开，离线可用

> 推荐本地保存一份，网络访问异常时可以直接打开本地文件。
